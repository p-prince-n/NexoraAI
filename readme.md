# Nexora AI – Autonomous AI Agent Builder

Nexora AI is an AI-powered agent builder platform that allows users to create, manage, and execute intelligent AI agents using simple natural-language prompts.

Users can define an agent's objective, instructions, tools, skills, and execution schedule. Agents can connect with external applications, perform automated tasks, and generate structured outputs.

The platform is designed to support continuous **24/7 agent execution**, including scheduled and recurring tasks, with a credit-based usage system.

## ✨ Features

- **AI Agent Creation:** Create AI agents using natural-language prompts.
- **AI-Powered Configuration:** Use Gemini AI to understand user prompts and generate agent configurations.
- **Agent Management:** View, run, pause, and delete your AI agents.
- **24/7 Automation:** Configure agents to execute manually, once, or on recurring schedules.
- **Tool Integrations:** Connect external applications and services through Composio.
- **Task Monitoring:** Track completed, running, failed, and scheduled tasks.
- **Execution History:** View agent execution results and generated outputs.
- **Credit-Based System:** Manage available credits and total credits for agent usage.
- **Authentication:** Secure user authentication and session management using Clerk.
- **Database Management:** Store users, agents, tasks, and related application data using Neon PostgreSQL and Drizzle ORM.

## 🤖 AI Agent Workflow

1. **Describe your agent:** Enter a natural-language prompt describing what you want the agent to accomplish.
2. **Generate configuration:** Gemini AI processes the prompt and generates an agent configuration.
3. **Configure tools:** Select the required integrations and capabilities.
4. **Set execution schedule:** Choose manual, one-time, or recurring execution.
5. **Execute agent:** The agent performs its assigned tasks using configured tools.
6. **View results:** Access the execution status and generated output through the Play page.

## ⏰ Scheduling and Automation

Nexora AI supports different execution modes:

| Schedule | Description |
|---|---|
| Manual | Run the agent whenever required. |
| Once | Execute the agent at a configured time. |
| Recurring | Schedule repeated executions. |

Recurring schedules can be configured for:

- Hourly
- Daily
- Weekly
- Monthly

Background execution and scheduling are handled through Inngest.

**Note:** Continuous 24/7 execution depends on the deployed application, configured background workers, and scheduling infrastructure being available.

## 💳 Credit-Based System

Nexora AI uses a credit-based system to manage agent usage.

Each user has two credit-related values:

- `availableCredits`: Credits currently available for usage.
- `totalCredits`: Total credits associated with the user's account.

The credit system is intended to manage usage and support future subscription or credit-purchase plans.

## 🚀 Getting Started

Follow these instructions to run Nexora AI locally.

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git
- A Neon PostgreSQL database
- A Clerk application
- A Google Gemini API key
- A Composio API key

Additional API credentials may be required for Browserbase and SerpAPI features.

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/nexora-ai.git

cd nexora-ai
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Configure Environment Variables

Create a `.env.local` file in the root directory.

```env
# App Setup
NEXT_PUBLIC_APP_URL=http://localhost:3000

# Neon Serverless PostgreSQL Database
DATABASE_URL=

# Clerk Authentication
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=
CLERK_SECRET_KEY=
NEXT_PUBLIC_CLERK_SIGN_IN_URL=/sign-in
NEXT_PUBLIC_CLERK_SIGN_UP_URL=/sign-up

# Google Gemini AI
NEXT_GOOGLE_GEMINI_API_KEY=
NEXT_GOOGLE_GEMINI_MODEL=gemini-3.5-flash-lite

# Composio Integration
NEXT_COMPOSIO_API_KEY=

# Browserbase
BROWSERBASE_API_KEY=
BROWSERBASE_AGENT_ID=

# SerpAPI
SERPAPI_API_KEY=

# Inngest
INNGEST_DEV=1
```

Replace the empty values with your actual credentials.

**Important:** Never commit `.env.local` or expose API keys and secret credentials in your GitHub repository.

### 4. Configure the Database

After configuring your Neon PostgreSQL connection, run your Drizzle migrations.

```bash
npx drizzle-kit generate
npx drizzle-kit migrate
```

### 5. Start the Development Server

```bash
npm run dev
```

Open your browser and visit:

[http://localhost:3000](http://localhost:3000)
